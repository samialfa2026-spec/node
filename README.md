تشغيل عُقد Bitping و Repocket باستخدام Docker Compose

يحتوي هذا المجلد على الإعدادات اللازمة لتشغيل عُقدتي Bitping و Repocket معاً في بيئة واحدة وبسهولة.

الملفات المرفقة:

1.
docker-compose.yml: الملف الأساسي الذي يحدد الخدمات وإعداداتها.

2.
.env.example: نموذج لملف المتغيرات البيئية (يجب تعبئته ببياناتك).

خطوات التشغيل:

1.
تجهيز ملف الإعدادات:
قم بنسخ ملف .env.example إلى ملف جديد باسم .env:

Bash


cp .env.example .env





2.
إدخال بياناتك:
افتح ملف .env وقم بتغيير القيم الافتراضية ببيانات حساباتك:

•
لـ Bitping: البريد الإلكتروني وكلمة المرور.

•
لـ Repocket: البريد الإلكتروني و مفتاح الـ API (تجدونه في لوحة تحكم Repocket).



3.
بدء التشغيل:
قم بتشغيل العُقد باستخدام الأمر التالي:

Bash


docker-compose up -d





ملاحظات هامة:

•
تم إعداد العُقد لتعمل تلقائياً عند إعادة تشغيل النظام (restart: always).

•
بيانات Bitping يتم حفظها في Volume مستقل لضمان عدم فقدان جلسة تسجيل الدخول.

•
تأكد من تثبيت Docker و Docker Compose على جهازك قبل البدء.
